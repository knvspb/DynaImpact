# Анализатор тензограмм

Программа с графическим интерфейсом для анализа цифровой тензограммы —
текстового файла записи "время – значение величины". Определяет для
заданного участка записи:

1. **Максимальное статическое значение** — по составляющей сигнала с
   наибольшим периодом (первая форма колебаний).
2. **Максимальное динамическое (абсолютное) значение** — в окрестности
   момента статического максимума, ширина окрестности настраивается.
3. **Динамический коэффициент** — отношение динамического значения к
   статическому.
4. **Частоты собственных колебаний** — спектральным анализом окна
   свободных колебаний после прохода нагрузки.

За ноль участка принимается среднее значение величины на "тихих"
отрезках в начале и в конце ВЫБРАННОГО УЧАСТКА (по умолчанию по 2 с).

## Формат входного файла

Поддерживаются два формата:

* **Текстовый** (.txt, .gru, .dat, .csv) — каждая строка:
  `время<пробел или Tab>значение`. Десятичный разделитель — точка или
  запятая. Пустые строки и нечисловые заголовки пропускаются.
* **.ana + .anp** (пара файлов с одинаковым именем: бинарные данные +
  текстовый заголовок прибора). В диалоге "Открыть файл..." можно
  выбрать любой из двух файлов пары — второй находится автоматически
  по тому же имени рядом. Поддерживается формат данных `FORMAT f2`/`f4`
  (32-битные float, little-endian; частота дискретизации берётся из
  поля `FRQ` заголовка). Сопроводительная информация из заголовка
  (канал, дата/время начала записи, единицы измерения и т.п.) сразу
  подставляется в поле "Комментарий" на вкладке "2. Анализ".

## Работа с программой (три вкладки)

**Этап 1 — файл и участок**

1. "Открыть файл..." — загружается запись, строится график тензограммы
   целиком. Панель инструментов matplotlib под графиком позволяет
   масштабировать и панорамировать запись (лупа/крестик), чтобы найти
   нужный момент в длинной записи.
2. Флажок "Не отображать участки без записи (значение ≡ 0) длительностью
   от, с" — опция для длинных записей, где часть времени канал физически
   не писал данные (значение застыло строго на нуле). Показ таких
   участков наравне с реальными вынуждает вертикальную ось графика
   захватывать 0, из-за чего интересующие колебания (например, в
   диапазоне 150..185) сжимаются в узкую полосу графика. При включении
   такие участки (длиннее указанного порога, по умолчанию 5 с — короче
   не трогаются, чтобы не задеть обычные переходы сигнала через ноль)
   просто не рисуются, и вертикальный масштаб подстраивается под
   реальные данные. Влияет только на отображение записи целиком — на
   сами данные, выбор участка и расчёт не влияет.
3. На вкладке показаны два независимых блока полей:
   * "Время события, с", "окно до, с", "окно после, с" — при изменении
     любого из них поля диапазона (следующий пункт) пересчитываются
     автоматически;
   * "Диапазон, с: от / до" — именно эти значения используются далее
     для анализа, независимо от того, откуда они взялись.
   Диапазон можно заполнить любым из способов, описанных в текстовой
   подсказке под полями: временем события и окнами до/после, протяжкой
   мыши по графику записи (флажок "Выбор мышью на графике" — пока он
   включён, масштабирование и панорамирование графика недоступны, мышь
   работает на выбор), либо вписав границы прямо в поля диапазона.
   Любой способ только обновляет поля и подсвечивает выбор красным
   прямо на графике полной записи — сама запись при этом не
   обрезается и никуда не пропадает, что позволяет заметить и
   исправить ошибочный выбор до перехода к расчёту. Панель инструментов
   matplotlib под графиком (лупа, крестик, стрелка назад) помогает
   точнее прицелиться перед выбором.
4. Кнопка "Выбрать" применяет именно текущие значения полей диапазона —
   только после этого нажатия данные вне диапазона отбрасываются:
   участок показывается в увеличенном масштабе для визуальной проверки,
   открывается вкладка "Анализ". Возврат на вкладку "1. Файл и участок"
   в любой момент снова показывает полную запись с подсветкой
   последнего диапазона, так что его можно скорректировать и выбрать
   заново.

**Этап 2 — анализ**

1. Указываются название точки расчёта и комментарий — для последующей
   идентификации результата (используются как имя папки и текст в
   отчёте при сохранении).
2. Настраиваются: длительность "нулевого" отрезка (по умолчанию 2 с),
   частота среза, отделяющая первую форму от старших форм колебаний
   (можно нажать "Авто" для автоматической оценки по спектру, либо
   ввести своё значение), ширина окрестности поиска динамического
   максимума вокруг статического максимума (по умолчанию ±1 с).
3. Настраиваются параметры спектрального анализа: задержка от момента
   статического максимума (по умолчанию 5 с) и длительность окна
   спектрального анализа (по умолчанию 10 с). Задержка нужна, чтобы
   окно приходилось на свободные колебания конструкции уже после
   прохода нагрузки — так спектр показывает частоты собственных
   колебаний, а не частотный состав самого воздействия.
4. Кнопка "Анализ" — выполняется расчёт и спектральный анализ,
   строится сетка из 4 графиков: обзор всего участка (динамика и
   первая форма), увеличенный вид, окно сигнала, использованное для
   спектрального анализа, и сам спектр с отмеченными пиковыми
   частотами. Увеличенный вид показывает фрагмент "от нуля до нуля" —
   от точки, где квазистатическая кривая уходит от нуля, до точки, где
   она возвращается к нулю (то есть весь "горб" статического
   воздействия целиком), с запасом, чтобы окрестность поиска динамики
   была видна полностью — это единственная его задача, для проверки
   соответствия статического и динамического максимумов.
   Под графиками, слева направо: числовые результаты и блок
   "Справочная информация" — метод определения частот (БПФ), частота
   дискретизации, разрешение спектра по частоте (Δf = 1/длина окна) и
   частота Найквиста для текущего окна спектрального анализа.
5. Кнопка "Сохранить отчёт..." — сохраняет всё в подпапку (см. раздел
   "Сохранение отчёта" ниже).

**Этап 3 — расширенный спектральный анализ**

Открывается после выполнения основного анализа на этапе 2 (использует
его статический максимум и ноль участка). Позволяет проверить, какая
из обнаруженных в спектре частот — устойчивая частота собственных
колебаний конструкции, а какая — случайный/переходный пик:

1. Задаются длина окна спектра (та же логика, что на этапе 2) и
   диапазон задержек от максимума — "от", "до" и шаг (по умолчанию
   0.5 с).
2. Кнопка "Запустить развёртку" — для каждой задержки в заданном
   диапазоне выполняется спектральный анализ (окно фиксированной
   длины, сдвигаемое по записи), и результаты выводятся:
   * таблицей — по строке на задержку, до 5 обнаруженных пиковых
     частот в каждой;
   * диаграммой — точка на каждый пик каждой задержки (ось X —
     задержка, ось Y — частота пика, цвет — амплитуда). Устойчивая
     частота выглядит как горизонтальная полоса точек на одной и той
     же высоте почти при любой задержке — это и есть частота
     собственных колебаний; случайные/переходные пики появляются
     нерегулярно и не образуют такой полосы.

## Запуск из исходного кода

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+ с Tk (в стандартной установке python.org для
Windows Tk включён по умолчанию).

## Сборка .exe для Windows

Сборка выполняется на Windows (PyInstaller не выполняет кросс-сборку
с Linux/Mac на Windows):

```cmd
build_exe.bat
```

или вручную:

```cmd
pip install -r requirements.txt
python -m PyInstaller --onefile --windowed --name TensogramAnalyzer main.py
```

Готовый файл появится в `dist\TensogramAnalyzer.exe`.

## Метод расчёта

* Ноль участка = среднее значение на первых и последних N секундах
  выбранного отрезка (по умолчанию N = 2 с) — предполагается, что это
  участки без воздействия.
* Из сигнала за вычетом нуля с помощью БПФ (после удаления линейного
  тренда) оценивается частота первой формы колебаний — наименьшая
  значимая частота, для которой на участке укладывается не менее двух
  периодов, но не выше 1 Гц: для реальных сооружений первая
  (основная) форма собственных колебаний практически всегда ниже этого
  предела (например, характерный период проезда автомобиля по мосту —
  порядка нескольких секунд), а более высокочастотные пики в спектре
  "тихого" участка — это шум или старшие формы, а не первая форма.
* Строится "статическая" кривая — низкочастотная (Баттерворт 2-го
  порядка, фазово-нейтральная фильтрация `filtfilt`) с автоматически
  подбираемой частотой среза. Одиночный "горб" статического
  воздействия обычно несинусоидален и даёт в спектре не одну частоту,
  а частоту первой формы и набор её гармоник убывающей амплитуды;
  срез сразу за частотой первой формы обрезал бы эти гармоники и
  занижал статический максимум. Поэтому частота среза подбирается по
  первому достаточно широкому провалу в спектре после частоты первой
  формы (в пределах первых нескольких герц — чтобы поиск не "уезжал"
  на шум или реальные высокочастотные вибрации далеко за пределами
  разумного) — там, где гармоники формы нагружения уже затухли, а
  старшие формы/вибрации конструкции ещё не начались. Если чёткого
  провала нет, используется запасной вариант (×1.6 от частоты первой
  формы). Максимум по модулю полученной кривой — максимальное
  статическое значение.
* В окрестности момента этого максимума (по умолчанию ±1 с,
  настраивается) в исходном (нефильтрованном) сигнале ищется максимум
  по модулю — максимальное динамическое значение.
* Динамический коэффициент = |динамическое| / |статическое|.

Проверка корректности: на "тихих" участках в начале и в конце отрезка
(где нет воздействия) статическая кривая должна практически совпадать
с исходным сигналом — оба близки к нулю. Это видно на нижнем
(увеличенном) графике результата анализа.

Автоматически предложенная частота среза — разумное значение по
умолчанию; при необходимости её можно скорректировать вручную,
ориентируясь на график (в частности, на совпадение кривых в "тихих"
зонах) и опыт интерпретации конкретной записи.

### Спектральный анализ (частоты собственных колебаний)

Для окна `[t_static_max + задержка, t_static_max + задержка + длительность]`
(данные берутся из полной записи, а не только из ранее выбранного
участка) строится амплитудный спектр (БПФ после удаления линейного
тренда) и в нём ищутся пиковые частоты — они выводятся как оценка
частот собственных колебаний конструкции. Задержка нужна, чтобы это
окно приходилось на свободные колебания уже после прохода нагрузки, не
искажённые частотным составом самого воздействия.

## Сохранение отчёта

Кнопка "Сохранить отчёт..." создаёт в выбранной папке подпапку с
названием точки расчёта и сохраняет туда:

* `report.pdf` — сводка (название, комментарий, все числовые
  результаты) и все графики результата анализа;
* `values.csv` — те же числовые результаты в табличном виде;
* `segment_data.csv` — временной ряд участка (время, измеренное
  значение, значение от нуля участка, первая форма/статика);
* `spectrum.csv` и `spectral_window.csv` — спектр и временной ряд окна
  спектрального анализа;
* `overview.png`, `zoom.png`, `spectral_window.png`, `spectrum.png` —
  отдельные изображения всех графиков.

Если название точки не задано, подпапка называется "точка_расчёта".
