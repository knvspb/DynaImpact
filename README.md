# Анализатор тензограмм

Программа с графическим интерфейсом для анализа цифровой тензограммы —
текстового файла записи "время – значение величины". Определяет для
заданного участка записи:

1. **Максимальное статическое значение** — по составляющей сигнала с
   наибольшим периодом (первая форма колебаний).
2. **Максимальное динамическое (абсолютное) значение** — в окрестности
   момента статического максимума, ширина окрестности настраивается.
3. **Коэффициент динамичности** — отношение динамического значения к
   статическому.

За ноль участка принимается среднее значение величины на "тихих"
отрезках в начале и в конце ВЫБРАННОГО УЧАСТКА (по умолчанию по 2 с).

## Формат входного файла

Текстовый файл, каждая строка: `время<пробел или Tab>значение`.
Десятичный разделитель — точка или запятая. Пустые строки и нечисловые
заголовки пропускаются.

## Работа с программой (два этапа)

**Этап 1 — файл и участок**

1. "Открыть файл..." — загружается запись, строится график тензограммы
   целиком.
2. Указываются: время события (с), окно до (по умолчанию 10 с), окно
   после (по умолчанию 10 с).
3. Кнопка "Выбрать" — выбранный участок отображается в увеличенном
   масштабе для визуальной проверки, открывается вкладка "Анализ".

**Этап 2 — анализ**

1. Настраиваются: длительность "нулевого" отрезка (по умолчанию 2 с),
   частота среза, отделяющая первую форму от старших форм колебаний
   (можно нажать "Авто" для автоматической оценки по спектру, либо
   ввести своё значение), ширина окрестности поиска динамического
   максимума вокруг статического максимума.
2. Кнопка "Анализ" — выполняется расчёт, на графике показываются:
   исходный сигнал участка (за вычетом нуля), выделенная первая форма
   (статика), точка статического максимума, точка динамического
   максимума и окрестность поиска. Под графиком выводятся числовые
   результаты.

## Запуск из исходного кода

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+ с Tk (в стандартной установке python.org для
Windows Tk включён по умолчанию).

## Сборка .exe для Windows

Сборка выполняется на Windows (PyInstaller не выполняет кросс-сборку
с Linux/Mac на Windows):

```cmd
build_exe.bat
```

или вручную:

```cmd
pip install -r requirements.txt
python -m PyInstaller --onefile --windowed --name TensogramAnalyzer main.py
```

Готовый файл появится в `dist\TensogramAnalyzer.exe`.

## Метод расчёта

* Ноль участка = среднее значение на первых и последних N секундах
  выбранного отрезка (по умолчанию N = 2 с) — предполагается, что это
  участки без воздействия.
* Из сигнала за вычетом нуля с помощью БПФ (после удаления линейного
  тренда) оценивается частота первой формы колебаний — наименьшая
  значимая частота, для которой на участке укладывается не менее двух
  периодов.
* Строится "статическая" кривая — низкочастотная (Баттерворт,
  фазово-нейтральная) фильтрация с частотой среза чуть выше частоты
  первой формы (по умолчанию ×1.6, настраивается). Максимум по модулю
  этой кривой — максимальное статическое значение.
* В окрестности момента этого максимума (по умолчанию — один период
  первой формы) в исходном (нефильтрованном) сигнале ищется максимум
  по модулю — максимальное динамическое значение.
* Коэффициент динамичности = |динамическое| / |статическое|.

Автоматически предложенные частота среза и окрестность — это разумные
значения по умолчанию; при необходимости их можно скорректировать
вручную, ориентируясь на график и опыт интерпретации конкретной записи.
