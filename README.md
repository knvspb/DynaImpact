# Анализатор тензограмм

Программа с графическим интерфейсом для анализа цифровой тензограммы —
текстового файла записи "время – значение величины". Определяет для
заданного участка записи:

1. **Максимальное статическое значение** — по составляющей сигнала с
   наибольшим периодом (первая форма колебаний).
2. **Максимальное динамическое (абсолютное) значение** — в окрестности
   момента статического максимума, ширина окрестности настраивается.
3. **Коэффициент динамичности** — отношение динамического значения к
   статическому.
4. **Частоты собственных колебаний** — спектральным анализом окна
   свободных колебаний после прохода нагрузки.

За ноль участка принимается среднее значение величины на "тихих"
отрезках в начале и в конце ВЫБРАННОГО УЧАСТКА (по умолчанию по 2 с).

## Формат входного файла

Текстовый файл, каждая строка: `время<пробел или Tab>значение`.
Десятичный разделитель — точка или запятая. Пустые строки и нечисловые
заголовки пропускаются.

## Работа с программой (два этапа)

**Этап 1 — файл и участок**

1. "Открыть файл..." — загружается запись, строится график тензограммы
   целиком. Панель инструментов matplotlib под графиком позволяет
   масштабировать и панорамировать запись (лупа/крестик), чтобы найти
   нужный момент в длинной записи.
2. Участок можно выбрать двумя способами:
   * вручную — указать время события (с), окно до (по умолчанию 10 с)
     и окно после (по умолчанию 10 с), затем нажать "Выбрать";
   * мышью — включить флажок "Выбор мышью на графике" и протянуть
     нужный отрезок по горизонтали прямо на графике записи; поля
     времени события/окон при этом заполняются автоматически, и
     участок выбирается сразу. Пока флажок включён, масштабирование и
     панорамирование недоступны (мышь работает на выбор) — снимите
     флажок, чтобы снова листать/масштабировать запись.
3. Выбранный участок отображается в увеличенном масштабе для
   визуальной проверки, открывается вкладка "Анализ".

**Этап 2 — анализ**

1. Указываются название точки расчёта и комментарий — для последующей
   идентификации результата (используются как имя папки и текст в
   отчёте при сохранении).
2. Настраиваются: длительность "нулевого" отрезка (по умолчанию 2 с),
   частота среза, отделяющая первую форму от старших форм колебаний
   (можно нажать "Авто" для автоматической оценки по спектру, либо
   ввести своё значение), ширина окрестности поиска динамического
   максимума вокруг статического максимума (по умолчанию ±1 с).
3. Настраиваются параметры спектрального анализа: задержка от момента
   статического максимума (по умолчанию 5 с) и длительность окна
   спектрального анализа (по умолчанию 10 с). Задержка нужна, чтобы
   окно приходилось на свободные колебания конструкции уже после
   прохода нагрузки — так спектр показывает частоты собственных
   колебаний, а не частотный состав самого воздействия.
4. Кнопка "Анализ" — выполняется расчёт и спектральный анализ,
   строится сетка из 4 графиков: обзор всего участка (динамика и
   первая форма), увеличенный вид с проверкой максимумов, окно
   сигнала, использованное для спектрального анализа, и сам спектр с
   отмеченными пиковыми частотами. Под графиками выводятся числовые
   результаты, включая определённые частоты.
5. Кнопка "Сохранить отчёт..." — сохраняет всё в подпапку (см. раздел
   "Сохранение отчёта" ниже).

## Запуск из исходного кода

```bash
pip install -r requirements.txt
python main.py
```

Требуется Python 3.10+ с Tk (в стандартной установке python.org для
Windows Tk включён по умолчанию).

## Сборка .exe для Windows

Сборка выполняется на Windows (PyInstaller не выполняет кросс-сборку
с Linux/Mac на Windows):

```cmd
build_exe.bat
```

или вручную:

```cmd
pip install -r requirements.txt
python -m PyInstaller --onefile --windowed --name TensogramAnalyzer main.py
```

Готовый файл появится в `dist\TensogramAnalyzer.exe`.

## Метод расчёта

* Ноль участка = среднее значение на первых и последних N секундах
  выбранного отрезка (по умолчанию N = 2 с) — предполагается, что это
  участки без воздействия.
* Из сигнала за вычетом нуля с помощью БПФ (после удаления линейного
  тренда) оценивается частота первой формы колебаний — наименьшая
  значимая частота, для которой на участке укладывается не менее двух
  периодов.
* Строится "статическая" кривая — низкочастотная (Баттерворт 2-го
  порядка, фазово-нейтральная фильтрация `filtfilt`) с автоматически
  подбираемой частотой среза. Одиночный "горб" статического
  воздействия обычно несинусоидален и даёт в спектре не одну частоту,
  а частоту первой формы и набор её гармоник убывающей амплитуды;
  срез сразу за частотой первой формы обрезал бы эти гармоники и
  занижал статический максимум. Поэтому частота среза подбирается по
  первому достаточно широкому провалу в спектре после частоты первой
  формы — там, где гармоники формы нагружения уже затухли, а старшие
  формы/вибрации конструкции ещё не начались. Если чёткого провала
  нет, используется запасной вариант (×1.6 от частоты первой формы).
  Максимум по модулю полученной кривой — максимальное статическое
  значение.
* В окрестности момента этого максимума (по умолчанию ±1 с,
  настраивается) в исходном (нефильтрованном) сигнале ищется максимум
  по модулю — максимальное динамическое значение.
* Коэффициент динамичности = |динамическое| / |статическое|.

Проверка корректности: на "тихих" участках в начале и в конце отрезка
(где нет воздействия) статическая кривая должна практически совпадать
с исходным сигналом — оба близки к нулю. Это видно на нижнем
(увеличенном) графике результата анализа.

Автоматически предложенная частота среза — разумное значение по
умолчанию; при необходимости её можно скорректировать вручную,
ориентируясь на график (в частности, на совпадение кривых в "тихих"
зонах) и опыт интерпретации конкретной записи.

### Спектральный анализ (частоты собственных колебаний)

Для окна `[t_static_max + задержка, t_static_max + задержка + длительность]`
(данные берутся из полной записи, а не только из ранее выбранного
участка) строится амплитудный спектр (БПФ после удаления линейного
тренда) и в нём ищутся пиковые частоты — они выводятся как оценка
частот собственных колебаний конструкции. Задержка нужна, чтобы это
окно приходилось на свободные колебания уже после прохода нагрузки, не
искажённые частотным составом самого воздействия.

## Сохранение отчёта

Кнопка "Сохранить отчёт..." создаёт в выбранной папке подпапку с
названием точки расчёта и сохраняет туда:

* `report.pdf` — сводка (название, комментарий, все числовые
  результаты) и все графики результата анализа;
* `values.csv` — те же числовые результаты в табличном виде;
* `segment_data.csv` — временной ряд участка (время, измеренное
  значение, значение от нуля участка, первая форма/статика);
* `spectrum.csv` и `spectral_window.csv` — спектр и временной ряд окна
  спектрального анализа;
* `overview.png`, `zoom.png`, `spectral_window.png`, `spectrum.png` —
  отдельные изображения всех графиков.

Если название точки не задано, подпапка называется "точка_расчёта".
