Второй вариант приложения (работает прямо в браузере, без установки). Полнофункциональная версия с установкой — Windows-приложение (исходный код и .exe). Файлы обрабатываются локально в браузере — ничего не отправляется на сервер.

только для отображения; на данные и расчёт не влияет
— именно этот диапазон используется далее для анализа
Диапазон можно задать: временем события и окнами до/после (поля "Диапазон" пересчитываются автоматически), протяжкой мыши по графику записи (включите флажок "Выбор мышью" выше — для масштабирования и панорамирования графика снимите его), либо вписав границы прямо в поля "Диапазон". Любой способ только обновляет поля и подсвечивает выбор на графике — сама запись не обрезается и никуда не пропадает. Данные обрезаются только по нажатию кнопки "Выбрать". Возврат на эту вкладку в любой момент снова показывает полную запись с подсветкой последнего диапазона.
